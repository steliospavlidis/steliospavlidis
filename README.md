### 🛡️ What I'm building

**[whatoblock.com](https://whatoblock.com)** is live threat intelligence your firewall can use.
A network of HoneyBot sensors records unsolicited traffic and classifies every source as a
**scanner, botnet C2, abusive proxy or DDoS source**, then turns it into firewall-ready blocklists
(TXT · CSV · JSON · firewall formats) for firewalls, SIEMs and scripts.

- 🔎 Scanner recon by port, protocol, ASN and country
- 🤖 Botnet C2 tracking with malware samples
- 🌐 Open proxy, Tor, datacenter and residential proxy intel
- 📦 Open data: DNS / NTP / SSDP datasets
